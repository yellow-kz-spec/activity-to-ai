# MVP Specification

Activity to MD развивается как Android-конвертер тренировок в Markdown с несколькими адаптерами источников.

## Текущая рабочая функциональность

### Garmin Connect

1. Пользователь открывает тренировку Garmin и нажимает **Поделиться**.
2. Garmin передает публичную ссылку через Android Share Sheet.
3. Пользователь выбирает **Activity to MD**.
4. Приложение принимает и проверяет Garmin Share Link, загружает доступные публичные данные, определяет тип тренировки, исключает карты/фотографии/точные координаты, формирует Markdown и сохраняет его в настроенную папку.
5. Пользователь получает краткое сообщение об успехе или ошибке.

Garmin не требует логина или OAuth. После первоначального выбора папки полный экран приложения не нужен.

## Ближайшая реализация

### Strava

- принять Strava share intent (`ACTION_SEND`, `image/*`, URL в `EXTRA_TEXT`);
- не использовать передаваемое изображение как основной источник данных;
- однократно подключить аккаунт через OAuth;
- определить активность по share URL;
- получить подробности и потоки через Strava API;
- преобразовать результат в ту же Markdown-систему с поддержкой Strava-специфичных полей.

OAuth-подключение, защищенное локальное хранение токенов, обновление токенов и локальное отключение уже реализованы как первая фаза. Определение активности по share URL, получение данных через API и Markdown-экспорт Strava пока не реализованы.

## Целевая граница архитектуры

`Activity Input → Source Detector → Source Adapter → NormalizedActivity → Markdown Exporter → output folder`

Это направление планируемого рефакторинга, а не утверждение о текущей структуре кода. Общая модель должна поддерживать общие поля и расширения конкретного источника.

## Интерфейс и формат

Основной выходной формат — `.md`. Допускаются только необходимые системные элементы, однократная настройка папки, экран подключения источника и краткие состояния обработки. JSON может рассматриваться после стабилизации основного сценария.

## Будущие улучшения

После Garmin и Strava можно рассматривать новые адаптеры (например, COROS, Suunto, Polar, Fitbit, Apple-экспорты или FIT/TCX/GPX). Они не являются текущей поддерживаемой функциональностью.
