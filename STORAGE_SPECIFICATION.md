# Storage Specification

## Выбор папки

Android ограничивает прямой доступ приложений к произвольным папкам.

Поэтому при первом использовании приложение должно один раз открыть системный выбор папки через Storage Access Framework.

Пользователь выбирает постоянную папку для экспортов.

Приложение сохраняет выданное разрешение и использует эту папку для следующих Markdown-экспортов независимо от источника активности.

## Если папка не выбрана

При первом поддерживаемом share-вызове:
1. принять и временно сохранить входные данные активности;
2. открыть системный выбор папки;
3. после выбора продолжить обработку автоматически.

## Имя файла

Рекомендуемый шаблон:

`YYYY-MM-DD_HH-mm_<activity-type>_<distance>.md`

Пример:

`2026-07-06_19-46_running_9.03km.md`

Если имя уже существует, добавить суффикс:

`_2`, `_3` и далее.
