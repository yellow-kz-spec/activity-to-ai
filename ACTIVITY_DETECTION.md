# Activity Detection

Приложение должно самостоятельно определить источник входа, а затем тип тренировки из данных соответствующего источника. Сейчас это реализовано для Garmin; source detection и общая нормализованная модель являются направлением рефакторинга.

## Минимально поддерживаемые типы MVP

- running;
- cycling;
- walking;
- hiking;
- other.

## Правила

- Пользователь не выбирает тип вручную.
- Тип определяется адаптером по данным источника; текущая Garmin-реализация использует поля Garmin.
- Если точный тип неизвестен, использовать `other`.
- Набор экспортируемых секций зависит от доступных данных, а не только от типа активности.
- Отсутствие необязательной метрики не считается ошибкой.
- Источник определяется без ручного выбора пользователя.
