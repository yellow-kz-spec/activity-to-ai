# Project Vision

## Цель

Activity to MD — Android-приложение, которое превращает данные тренировок из поддерживаемых фитнес-платформ в структурированные Markdown-файлы для анализа ИИ-ассистентами.

Garmin Connect является текущим рабочим источником. Strava — следующий источник в активной разработке. Будущие источники должны подключаться через отдельные адаптеры без переработки Markdown-экспортера.

## Основной пользовательский сценарий

Пользователь не должен скачивать FIT-файл, вручную копировать URL или данные, выбирать тип тренировки либо настраивать формат при каждом экспорте.

Нормальный сценарий: **открыть тренировку → Поделиться → Activity to MD → получить `.md` в настроенной папке**.

Для источника с авторизацией допускается однократная настройка. Например: открыть Activity to MD → **Connect Strava** → пройти OAuth. Последующие экспорты должны снова оставаться share-first.

## Принципы

- Android-first и share-first.
- Минимум действий после Share.
- Markdown — основной продуктовый результат.
- Общие данные нормализуются, полезные метрики источника сохраняются как расширения.
- Отсутствие метрики, которой нет у конкретного источника, не является ошибкой.
- Не воспроизводить интерфейс Garmin, Strava, карты или декоративные элементы.
- Не выполнять спортивный анализ внутри приложения.
- Не включать точные GPS-координаты в итоговый Markdown без явной причины.
